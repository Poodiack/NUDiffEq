    Section 1.5 First-Order Linear Equations

    Objectives

    • To understand that any first-order linear differential equation
      \begin{equation*} y' + p(x) y = f(x) \end{equation*}
      can be solved by multiplying each side of the equation by an integrating factor.
      🔗
      🔗
    • To understand the existence and uniqueness of solutions to first-order initial value problems.
      🔗
      🔗
    🔗
    We recall that a first-order differential equation is linear if the dependent variable (let’s use \(y\) here) and its derivatives appear only to the first power, not multiplied by each other, and not buried within a function (no \(e^y\)’s, for instance). In particular, we will say that a first-order differential equation is linear if we can write it in the form
    \begin{equation} a_1(x)y'(x) + a_0(x) y(x) = b(x)\tag{1.5.1} \end{equation}
    for some functions \(a_1, a_0\) and \(b\text{.}\) Our goal, as it always is when we start out, is to solve this equation explicitly for \(y(x)\text{.}\) In particular, we must have that \(a_1(x)\ne 0\) in some interval. Assuming that it is, we can divide (1.5.1) through by \(a_1(x)\) and we get our standard form
     1 
    By standard form, we mean a form which we use to check the type of a differential equation. So if we want to check if a given differential equation is a linear, first-order equation, we try to put it into the standard form and match up the parts.
    for a first-order linear differential equation:
    \begin{equation} \boxed{y' +p(x)y = f(x)}\tag{1.5.2} \end{equation}
    (We have suppressed the “of \(x\)”’s on the \(y\text{.}\))
    🔗
    We call the equation homogeneous if the function on the right-hand side \(f(x)=0\text{.}\)
    🔗

    Example 1.5.1. Is it linear?

    The equation \(y'=-3y+\sin x\) is linear. We can reorganize the equation into the standard form \(y'+3y=\sin x\) and then we can see that \(p(x) = 3\) and \(f(x) = \sin x\text{.}\)
    🔗
    🔗

    Example 1.5.2. Is it linear?

    The equation \(y'=y\sin x + x^3\) is linear. We can reorganize the equation into standard form and obtain \(y'-(\sin x)y = x^3\text{.}\) We then have that \(p(x) = -\sin y\) and \(f(x) = x^3\text{.}\)
    🔗
    🔗

    Example 1.5.3. Is it linear?

    The equation \(4y'+e^y x = 0\) is not linear. Although we can rewrite the equation in the form \(y' + \frac{x}4 e^y = 0\text{,}\) the dependent variable \(y\) is bound up in an exponential (\(e^y\)).
    🔗
    🔗

    Example 1.5.4. Is it linear?

    The equation \(yy'=2x\) is not linear because the dependent variable \(y\) and its derivative \(y'\) are multiplied together.
    🔗
    🔗

    Subsection 1.5.1 Solving First-Order Linear Differential Equations

    We can solve many first-order linear differential equations explicitly. In fact, we can get a general method for doing so by first attacking the special case of when our equation is homogeneous.
    🔗

    Subsubsection 1.5.1.1 The Homogeneous Case

    Remember that a first-order linear differential equation is homogeneous if, when it’s written in standard form, the right-hand side is 0. That is, we can write the equation (1.5.2) in the form
    \begin{equation*} y'+ p(x) y = 0. \end{equation*}
    We now make the following
    🔗

    Claim 1.5.5.

    If our first-order linear differential equation is homogeneous, then it is separable.
    🔗
    🔗
    We can see this by simply rewriting the differential equation as
    \begin{equation*} y'=-p(x) y \quad\text{or}\quad \frac{dy}{dx} = -p(x) y. \end{equation*}
    Thus we can use the methods of Section 1.4 to solve. That is, we can separate and integrate:
    \begin{align*} \frac{dy}{y} \amp = -p(x)\,dx\\ \int\frac1{y}\,dy \amp = -\int p(x)\,dx\\ \ln |y| \amp = -\int p(x)\,dx \end{align*}
    This means that the general solution of the homogeneous equation can be written as
    \begin{equation} y = e^{-\int p(x)\,dx}\tag{1.5.3} \end{equation}
    🔗

    Example 1.5.6.

    Suppose we wish to solve the homogeneous first-order linear differential equation (that’s a mouthful!)
    \begin{equation*} y'+(\cos x)y = 0. \end{equation*}
    We have that \(p(x)=\cos x\text{.}\) Therefore, by (1.5.3), we have that
    \begin{align*} y \amp = e^{-\int \cos x\,dx} \\ \amp =e^{-\sin x + C}\\ \amp = e^C\cdot e^{-\sin x}. \end{align*}
    Setting \(A=e^C\)m we see that the general solution is
    \begin{equation*} y = Ae^{-\sin x}, \end{equation*}
    where \(A\ne 0\text{.}\) However, we note that if \(A=0\text{,}\) this would make \(y=0\) which is a solution to the original differential equation. So we can let \(A\) be any real number.
    🔗
    One thing we haven’t done much of is to check our solutions. It’s a good habit to have. We do this by computing the derivative of \(y\) and then substituting our answer \(y\) and its derivative \(y'\) into the original differential equation. If \(y=Ae^{-\sin x}\text{,}\) we use the chain rule to compute
    \begin{equation*} y' = Ae^{-\sin x}\cdot\frac{d}{dx}(-\sin x) = -A\cos x e^{-\sin x} \end{equation*}
    and so
    \begin{equation*} y' + (\cos x)y = -A\cos x\, e^{-\sin x} + (\cos x)Ae^{-\sin x} \equiv 0, \end{equation*}
    as expected.
    🔗
    🔗
    🔗

    Subsubsection 1.5.1.2 The Non-homogeneous Case

    Now we examine the case where the right-hand side of our first-order linear differential equation is not zero; that is \(f(x)\ne 0\text{.}\) In this case, we will employ a trick. We will multiply both sides of our differential equation by a positive function \(\mu(x)\) so that the left-hand side is a perfect product rule derivative.
    🔗

    Remark 1.5.7. Product Rule.

    The derivative of the product of two differentiable functions, \(f(x)\) and \(g(x)\) is given by
    \begin{equation*} \frac{d}{dx}[f(x)g(x)] = f(x)g'(x) + f'(x)g(x) \end{equation*}
    🔗
    🔗

    Example 1.5.8. What we’re trying to do here.

    Let us walk through an example to illustrate the technique that we’re going to use here.
    🔗
    Suppose we wish to solve the non-homogeneous first-order linear differential equation
    \begin{equation*} y' + 2y = xe^{-2x}. \end{equation*}
    This is linear with \(p(x) = 2\) and \(f(x) = xe^{-2x}\text{.}\) (This equation is not separable though.) We will multiply the entire equation by the function \(\mu(x)=e^{2x}\text{.}\) (For now, don’t worry about where our choice for \(\mu\) came from.) We then get
    \begin{gather*} y' + 2y = xe^{-2x} \\ e^{2x}(y'+2y) = e^{2x}(xe^{-2x}) \\ e^{2x}y' + 2e^{2x}y = x, \end{gather*}
    since \(e^{-2x} = \frac1{e^{2x}}\text{.}\) If we look at the left-hand side now, we note that it is the derivative of the product \(e^{2x}y\text{.}\) (Check this using implicit differentiation!) Therefore, we arrive at the equation
    \begin{equation*} \frac{d}{dx}(e^{2x}y) = x \end{equation*}
    We now integrate both sides with respect to \(x\) (the independent variable). On the left-hand side, we take advantage of the Fundamental Theorem of Calculus to note that the integral of a derivative gives us back the original function. Therefore, we have
    \begin{gather*} \int \frac{d}{dx}(e^{2x}y)\,dx = \int x\,dx \\ e^{2x} y = \frac{x^2}{2} + C, \end{gather*}
    where, as before, we agree to move all the arbitrary constants of integration to the end of the right-hand side and combine them into one big “C”. We can now solve for \(y\) by multiplying both sides by \(e^{-2x}\) (or dividing both sides by \(e^{2x}\) if you prefer) to get
    \begin{equation*} \boxed{y = e^{-2x}\cdot\frac{x^2}{2} + Ce^{-2x}}. \end{equation*}
    🔗
    🔗
    The example showed the technique we will use to solve non-homogeneous first-order linear equations, but left one burning question: How did we pick the function \(\mu(x)\) that we multiplied the entire equation by?. The function \(\mu\) is called an integrating factor. The idea is that multiplying the entire equation through by \(\mu\) should give us a perfect product rule derivative on the left-hand side.
    🔗
    Fortunately, we can find a formula for this integrating factor. The left-hand side of our differential equation here, recall, has form \(y' + p(x)y\text{.}\) When we multiply through by the integrating factor \(\mu\text{,}\) we obtain
    \begin{equation*} \mu(x)\left(y' + p(x)y\right) = \mu\, y' + (\mu \,p)y. \end{equation*}
    We want \(\mu \,y' + (\mu\, p)y = \frac{d}{dx}(\mu \,y)\text{.}\) By the product rule, though, we know that \(\frac{d}{dx}(\mu \,y) = \mu\,y' + \mu'\,y\text{.}\) So we need
    \begin{gather*} \mu \,y' + (\mu\,p)y = \mu\,y' + \mu'\,y\\ (\mu\, p)y = \mu'\,y\\ \mu\,p = \mu' \Longrightarrow \mu' - p\,\mu = 0. \end{gather*}
    This last differential equation is first-order, linear, and homogeneous. So we can use the method of Subsubsection 1.5.1.1 to solve the equation and get that the formula for the integrating factor is
    \begin{equation*} \boxed{\mu(x) = e^{\int p(x)\,dx}}. \end{equation*}
    🔗

    Remark 1.5.9.

    You may be thinking, “Is there a typo? Didn’t we drop a minus sign up in the exponent there?” The answer is NO. Because the differential equation for \(\mu\) had a minus sign before the \(p\text{,}\) this extra minus sign multiplies the minus sign in our homogeneous solution and cancels it out.
    🔗
    🔗
    In particular, multiplying through by the integrating factor \(\mu\) should make the left-hand side of the differential equation into the derivative of the product \(\mu\,y\text{.}\)
    🔗

    Example 1.5.10.

    Consider the differential equation
    \begin{equation*} y'-y = xe^x. \end{equation*}
    This equation is linear with \(p(x)=-1\) and \(f(x) = xe^x\text{.}\) We first find the integrating factor \(\mu(x)\text{:}\)
    \begin{equation*} \mu(x) = e^{\int p(x)\,dx} = e^{(-1)\,dx} = e^{-x}. \end{equation*}
    (You may be wondering where the \({}+C\) is. For an integrating factor, we just need one solution that works, not all of them. So we make life easier by agreeing to pick the one with \(C=0\text{.}\))
    🔗
    We now multiply our differential equation through by our integrating factor \(\mu(x) = e^{-x}\text{.}\)
    \begin{gather*} y'-y = xe^x\\ e^{-x}(y'-y) = e^{-x}(xe^x)\\ e^{-x}y' - e^{-x}y = x \end{gather*}
    We can now see that the left-hand side is the derivative of \(\mu\,y = e^{-x} y\text{.}\) We thus write
    \begin{gather*} \frac{d}{dx}(e^{-x}y) = x\\ \int \frac{d}{dx}(e^{-x}y)\,dx = \int x\,dx\\ e^{-x}y = \frac{x^2}{2}+C \end{gather*}
    We now solve for \(y\) by multiplying through by \(e^x\) and we find that
    \begin{equation*} \boxed{y = e^x\cdot\frac{x^2}{2} + Ce^x}. \end{equation*}
    We can use MATLAB to check our answer.
    🔗
    🔗
    🔗

    Subsubsection 1.5.1.3 A General Formula

    We can actually derive a formula for solving the first-order linear differential equation (1.5.2)
    \begin{equation*} y'+p(x)y=f(x). \end{equation*}
    Suppose we have found our integrating factor \(\mu(x)=\int p(x)\,dx\text{.}\) As before, we multiply (1.5.2) by \(\mu(x)\text{:}\)
    \begin{equation*} \mu(x)\left(y'+p(x)y\right) = \mu(x)f(x). \end{equation*}
    We can now solve the equation by integrating both sides with respect to \(x\text{.}\)
    \begin{gather*} \frac{d}{dx}(\mu(x)y) = \mu(x)f(x)\\ \int \frac{d}{dx}(\mu(x) y)\,dx = \int \mu(x) f(x)\,dx\\ \mu(x)y = \int\mu(x) f(x)\,dx + C \end{gather*}
    Dividing the final expression by \(\mu(x)\) gives the explicit solution
    \begin{equation} \boxed{y=\frac1{\mu(x)}\left[\int \mu(x) f(x)\,dx + C\right]}.\tag{1.5.4} \end{equation}
    The equation (1.5.4) is important theoretically as the general solution of the first-order linear differential equation, we in no way are telling you to memorize it. Just follow the steps from the examples in this section.
    🔗
    🔗
    Let us now solve an initial value problem.
    🔗

    Example 1.5.11. Solving an Initial Value Problem.

    Solve the initial value problem
    \begin{equation} xy'+y=\cos x, \quad y(1)=2.\tag{1.5.5} \end{equation}
    Also, determine the behavior of the solution as \(x\to\infty\text{,}\) both by looking at the formula for the solution and by using a slope field.
    🔗
    Solution.
    We first put (1.5.5) by dividing through by \(x\text{.}\)
    \begin{equation*} y'+\frac1{x}\cdot y = \frac{\cos x}{x}. \end{equation*}
    In doing this, we assume that \(x\ne 0\text{.}\) We have that \(p(x)=1/x\) and \(f(x) = (\cos x)/x\text{.}\) Our integrating factor is
    \begin{equation*} \mu(x) = e^{\int p(x)\,dx} = e^{\int \frac1{x}\,dx} = e^{\ln x} = x. \end{equation*}
    (Remember that we can pick the simplest antiderivative of \(p(x)\text{.}\)) We multiply our equation by \(x\) which leads to
    \begin{equation*} \int (xy'+y)\,dx \equiv \int \frac{d}{dx}(xy)\,dx = \int \cos x\,dx. \end{equation*}
    This implies that \(xy = \sin x + C\text{.}\) Solving explicitly for \(y\) yields
    \begin{equation*} y = \frac{\sin x+C}{x}, \quad x\ne 0. \end{equation*}
    The initial condition tells us that when \(x=1\text{,}\) \(y=2\text{.}\) Substituting this in above leads to
    \begin{equation*} 2 = \frac{\sin 1 + C}{1} \Longrightarrow C = 2-\sin 1 \end{equation*}
    and the particular solution is
    \begin{equation*} \boxed{y=\frac{\sin x + 2 -\sin 1}{x}}. \end{equation*}
    From this formula, we see that \(y\to 0\) as \(x\to\infty\text{.}\) At \(x=0\text{,}\) \(y\) has a vertical asymptote.
    🔗
    We can use MATLAB to draw the slope field as well as the particular solution. To use the algorithm we used in earlier sections, we have to solve our differential equation for \(y'\text{:}\)
    \begin{equation*} y' = \frac{\cos x - y}{x}. \end{equation*}
    🔗
    % 1. Define the grid for the slope field
% Avoid x = 0 to prevent division by zero in the ODE
x_vals = linspace(0.1, 5, 25); 
y_vals = linspace(-2, 5, 25);
[X, Y] = meshgrid(x_vals, y_vals);

% 2. Calculate the slope (dy/dx) at each grid point
% Using the rearranged ODE: y' = (cos(x) - y) / x
S = (cos(X) - Y) ./ X;

% 3. Normalize the vector components to maintain uniform segment lengths
L = sqrt(1 + S.^2);
U = 1 ./ L;
V = S ./ L;

% 4. Create the plot window and draw the slope field
figure;
% Adjust the 0.5 scale factor to match your preference for segment length
quiver(X, Y, U, V, 0.5, 'Color', [0.5, 0.5, 0.5], 'LineWidth', 1);
hold on;

% 5. Define the ODE function handle for numerical integration
dydx = @(x, y) (cos(x) - y) / x;

% 6. Solve the ODE numerically through the point (1,2)
x_span = [1, 5]; % Forward integration path
y0 = 2;          % Initial condition at x = 1
[x_sol_fwd, y_sol_fwd] = ode45(dydx, x_span, y0);

x_span_bwd = [1, 0.1]; % Backward integration path toward x = 0
[x_sol_bwd, y_sol_bwd] = ode45(dydx, x_span_bwd, y0);

% Combine forward and backward results for a smooth, unbroken line
x_sol = [flipud(x_sol_bwd); x_sol_fwd];
y_sol = [flipud(y_sol_bwd); y_sol_fwd];

% 7. Plot the solution curve and the initial point
plot(x_sol, y_sol, 'r-', 'LineWidth', 2.5); % Solution curve in red
plot(1, 2, 'bo', 'MarkerFaceColor', 'b', 'MarkerSize', 8); % Target point in blue

% 8. Annotations and Layout Adjustments
title('Slope Field and Solution Curve for $x y'' + y = \cos(x)$', 'Interpreter', 'latex', 'FontSize', 14);
xlabel('$x$', 'Interpreter', 'latex', 'FontSize', 12);
ylabel('$y$', 'Interpreter', 'latex', 'FontSize', 12);
axis([0 5 -2 5]);
grid on;
legend('Slope Field', 'Solution Curve through (1,2)', 'Point (1,2)', 'Location', 'northeast');
hold off;
