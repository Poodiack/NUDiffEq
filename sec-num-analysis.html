    Section 1.6 Analyzing Equations Numerically

    Objectives

    • To understand that numerical algorithms such as Euler’s method allow the approximation of solutions to the initial value problems and that there are more efficient algorithms than Euler’s method such as those algorithms that use the Runge-Kutta methods.
      🔗
      🔗
    • To understand that Taylor’s Theorem is a very useful tool for studying differential equations.
      🔗
      🔗
    • To understand that error analysis of the rate of convergence is very important for any numerical algorithm.
      🔗
      🔗
    🔗
    As we’ve already seen, we can’t always find a solution to a first-order initial value problem
    \begin{equation} y'=f(x,y), \qquad y(x_0)=y_0\tag{1.6.1} \end{equation}
    analytically. It could be the case that we cannot integrate a function in terms of elementary functions, for instance. (It’s not you, it’s the integral!) However, we may still need a reasonable approximation of the solution curve to make estimates. We will explore some methods in this section on numerically approximating solutions to these problems.
    🔗
    Our initial value problem provides us with one point on the desired solution curve, namely \((x_0, y_0)\text{.}\) Our goal is to produce a set of discrete points
    \begin{equation*} (x_0, y_0), (x_1,y_1), (x_2, y_2), \dots, (x_N, y_N) \end{equation*}
    that can approximate points on the solution curve. For this purpose, we will insist that the \(x\)-coordinates be equally spaced. That is,
    \begin{equation*} x_j = x_0 + j\Delta x, \quad j = 1, 2, \dots, N \end{equation*}
    and the corresponding \(y_j\) is an approximation of the solution at \(x_j\text{;}\) that is, \(y_j\approx y(x_j)\text{.}\) Once this list of points is obtained, it is usually plotted by connecting the points by straight-line segments; or, if you are using a sophisticated computer package, a curve fitting routine may be used to fit a smooth curve through the points.
    🔗
    The presence of a \(\Delta x\) term may put us in mind of our previous work on defining definite integrals in terms of Riemann sums. As with that situation, our approximations improve as the step size \(\Delta x\) shrinks, but the calculations become difficult, especially because we humans are prone to rounding off answers, leading to error accumulating as we perform more calculations. Using computers can fend this off for awhile, but even computers have a maximum word size and run into this issue after several steps. Also, different methods have different error estimates based on the size of \(\Delta x\text{.}\)
    🔗

    Subsection 1.6.1 Euler’s method

    We have already seen the usefulness of slope (or direction) fields in visualizing solution curves. If we consider the initial value problem (1.6.1), we recall that we would draw a short line segment of slope \(m_0 = f(x_0, y_0)\) through the point \((x_0, y_0)\text{.}\) This line segment is part of the tangent line to the solution curve at \((x_0, y_0)\text{.}\)
    🔗
    Euler’s method is one of the oldest and simplest numerical methods for obtaining approximate solutions to the initial value problem (1.6.1). Visually, the method says that we would start at our initial point \((x_0, y_0)\) and follow the tangent line of slope \(f(x_0, y_0)\) until we arrive at a point \(\Delta x\) units to the right. This will bring us to the point \((x_1,y_1)\text{.}\) We recompute our slope as \(f(x_1,y_1)\) and follow a line segment of this slope from \((x_1,y_1)\) until we arrive at a point \(\Delta x\) units further to the right. This will bring us to the point \((x_2,y_2)\text{.}\) We then adjust our slope to be \(f(x_2,y_2)\) and follow the line segment of that slope from \((x_2,y_2)\) to \((x_3,y_3)\text{.}\) We continue in this manner until we reach the point \((x_N, y_N)\text{.}\) (See Figure 1.6.1.)
    🔗
    Notice that no derivatives of \(f\) have to be evaluated, just \(f\) itself.
    🔗

    Note 1.6.2. Algorithm for Euler’s Method.

    Given \(y'=f(x,y)\text{,}\) \(y(x_0)=y_0\text{,}\) our goal is to find approximate values of \(y(x)\) on the interval \(x_0\le x\le x_{\text{max}}\text{.}\)
    🔗
    1. Choose a small step size \(h=\Delta x = \frac{x_{\text{max}}-x_0}{N}\text{,}\) with \(N\) a positive integer.
      🔗
      🔗
    2. For \(n=0, 1, 2, \dots, N-1\text{,}\) compute
      \begin{align*} x_{n+1} \amp = x_n + h \\ y_{n+1} \amp = y_n + f(x_n,y_n)\,h. \end{align*}
      🔗
      🔗
    3. Plot the points \((x_0, y_0), (x_1, y_1), \dots (x_N, y_N)\) and connect them by drawing straight lines. This results in a piecewise linear approximation to \(y(x)\) on the interval \([x_0, x_\text{max}]\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 1.6.3.

    Approximate the solution of \(y'=x-y\text{,}\) \(y(0)=1\) on the interval \([0,2]\text{.}\)
    🔗
    Solution.
    We first note that \(f(x,y)=x-y\text{.}\)
    🔗
    Let’s first try this with \(N=4\) points. Then we have that \(h = (2-0)/4 = 0.5\text{.}\) It is helpful to make a table. The values \(x_n = x_0 + n\cdot h\) are all determined once \(h\) is chosen.
    🔗
    Thus \(\boxed{y(2)\approx 1.125}\text{.}\)
    🔗
    A couple of comments:
    🔗
    • The value of \(y_{n+1}\) at the end of each row is used as the value of \(y_n\) in the following row. The values of \(x_0\) and \(y_0\) come from the initial condition we’re given.
      🔗
      🔗
    • The function \(f(x_n,y_n)\) is the slope function and depends on the differential equation we’re given.
      🔗
      🔗
    • We can use MATLAB to produce a table:
      🔗
      % Define the differential equation y' = f(x, y)
f = @(x, y) x - y;

% Initial conditions
x0 = 0;
y0 = 1;
xmax = 2;

% Configuration
num_steps = 4;      % Number of steps to generate 4 points after the initial condition
h = (xmax - x0)/num_steps;

% Initialize arrays to hold the values
x = zeros(num_steps + 1, 1);
y = zeros(num_steps + 1, 1);
f_val = zeros(num_steps + 1, 1);

% Set the initial point
x(1) = x0;
y(1) = y0;
f_val(1) = f(x(1), y(1));

% Euler's Method loop
for n = 1:num_steps
    % Calculate next y value: y_next = y_curr + h * f(x_curr, y_curr)
    y(n+1) = y(n) + h * f_val(n);

    % Advance x
    x(n+1) = x(n) + h;

    % Calculate f(x, y) at the new point (except for the last point, where it's optional)
    if n < num_steps + 1
        f_val(n+1) = f(x(n+1), y(n+1));
    end
end

% Create and display the table
Step = (0:num_steps)';
EulerTable = table(Step, x, y, f_val, 'VariableNames', {'n', 'x_n', 'y_n', 'f(x_n,y_n)'});
disp(EulerTable);
      🔗
    🔗
    The differential equation in this example is linear: \(y'=x+y\Longrightarrow y'-y=x\text{.}\) Using the method from Section 1.5, we get that \(y=x-1+2e^{-x}\text{.}\) (Check this!) This gives the exact value of
    \begin{equation*} y(2) = 2-1+2e^{-2} \approx 1.27067. \end{equation*}
    The absolute error in our numerically computed value of \(y(2)\) in the above table is
    \begin{equation*} |1.27067 - 1.125| \approx 0.14567. \end{equation*}
    If the calculations are redone with \(N=8\text{,}\) that is with \(\Delta x = 0.25\text{,}\) the corresponding table is
    🔗
    Thus \(\boxed{y(2)\approx 1.200226}\text{.}\)
    🔗
    The error in the approximate value of \(y(2)\) is now
    \begin{equation*} |1.27067 - 1.200226|\approx 0.0704. \end{equation*}
    By cutting the step size \(\Delta x\) in half the error has been cut approximately in half, from 0.146 to 0.070. Figure 1.6.6 shows the two approximate solutions together plotted with the exact solution.
    🔗

    Subsection 1.6.2 Error and the Order of a Numerical Method

    We demonstrated Euler’s method above on a differential equation we knew how to solve; we would never use this method on such an equation. (Why approximate when we can get an exact answer, and then express that as a decimal?) This was done to convince you that such a method can get results.
    🔗
    We would use a numerical method in the case where we can’t get a solution analytically. Because of this, we are duty bound to estimate the error in using the numerical method.
    🔗
    There are two different types of error that can occur when solving a differential equation numerically. The first is called round-off error and is due to rounding off or chopping the result after each step of the procedure, in order to store it on a computer with fixed word size. For example, if \(y(0) = \frac13\text{,}\) and the computer has a word size of 4 decimal digits, then it would probably store \(y(0)\) as 0.3333, already introducing an error greater than 0.00003 into the calculation. Fortunately, modern computers can store a lot more digits than this so it is usually not a problem, unless the procedure requires a huge number of steps.
    🔗
    The type of error you really need to be concerned about is caused by the approximations made by whatever method you are using. This is called truncation error.
    🔗
    Suppose we’re trying to solve the initial value problem \(y'=f(x,y)\text{,}\) \(y(x_0) = y_0\) for \(y\text{.}\) If the slope function \(f\) can be differentiated enough times, \(y(x)\) could be approximated by the first \(N+1\) terms of its Taylor series about \(x=x_0\text{:}\)
    \begin{equation} y(x_0+h) = y(x_0) + y'(x_0)h + \frac{y''(x_0)h^2}{2!} + \cdots + \frac{y^{(N)}(x_0)h^N}{N!} + E_N(h)\tag{1.6.2} \end{equation}
    where the error \(E_N(h)\) is known by Taylor’s theorem to be
    \begin{equation} E_N(h) = \frac{x^{(N+1)}(\xi) h^{N+1}}{(N+1)!}\tag{1.6.3} \end{equation}
    for \(\xi\) some value of \(x\) between \(x_0\) and \(x_0+h\text{.}\)
