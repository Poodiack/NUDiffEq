    Section 1.4 Separable Differential Equations

    Objectives

    • To recall that a first-order differential equation is one that can be written in the form
      🔗
      \begin{equation*} \frac{dy}{dx} = F(x,y) \end{equation*}
      🔗
      🔗
    • To understand that a differential equation is separable if it can be written in the form
      🔗
      \begin{equation*} \frac{dy}{dx} = g(x)h(y) \end{equation*}
      🔗
      and by rewriting the equation in the form
      🔗
      \begin{equation*} N(y)\,dy = M(x)\,dx \end{equation*}
      🔗
      the equation can be solved by integrating both sides.
      🔗
      🔗
    🔗
    We are now in a place where we can begin actually solving some first-order linear differential equations. That is, we’re going to begin to learn how to find an actual formula for a solution to the equation, not just approximate it. We also will look at when we can do this because, as we’ve noted before, we cannot always.
    🔗
    We’ve seen that we can always write a first-order linear differential equation in the form
    🔗
    \begin{equation*} \frac{dy}{dx} = F(x,y) \end{equation*}
    🔗
    for some function \(F\text{.}\) There are a couple of special cases of this format where we can actually get a solution.
    🔗
    1. The right-hand side function \(F(x,y)=g(x)\text{;}\) that is, there’s only \(x\)’s on the right-hand side, no \(y\)’s. Then we can “multiply” both sides of the equation by \(dx\)
       1 
      We continue the custom from first-semester calculus that \(dy/dx\) is not a fraction, though we treat it like one from then on.
      to get
      🔗
      \begin{equation*} \frac{dy}{dx} = g(x) \Longrightarrow dy = g(x)\,dx. \end{equation*}
      🔗
      We then integrate both sides to get
      🔗
      \begin{equation*} y=\int g(x)\,dx \end{equation*}
      🔗
      or \(y=G(x) + C\text{,}\) where \(G\) is any antiderivative of \(g\text{.}\)
      🔗
      🔗
    2. The right-hand side function is \(F(x,y) = h(y)\text{;}\) that is, there’s only \(y\)’s on the right-hand side, no \(x\)’s. In this case, we have an autonomous equation and we could use the methods of the previous section (phase lines, slope fields) to find good approximations to a solution.
      🔗
      🔗
    🔗
    The issue comes when we do have both \(x\)’s and \(y\)’s on that right-hand side. The good news is that there are instances where we can fully solve the differential equation. We will explore these instances here and in the next few sections.
    🔗

    Subsection 1.4.1 Separable Differential Equations

    If we can write the right-hand side function \(F(x,y)\) as the product of a function of just \(x\) times a function of just \(y\text{,}\) then our differential equation often can be solved.
    🔗

    Definition 1.4.1.

    A first-order linear differential equation is called separable if it can be written in the form
    🔗
    \begin{equation*} \frac{dy}{dx} = g(x)h(y) \end{equation*}
    🔗
    🔗

    Example 1.4.2.

    The equation \(y'=xy+2y\) is separable because we can write it as \(y'=y(x+2)\) with \(g(x)=x+2\) and \(h(y) = y\text{.}\)
    🔗
    🔗

    Example 1.4.3.

    The equation \(y'=y+\cos x\) is not separable because it cannot be factored into the product of a function of just \(x\) and a function of just \(y\text{.}\)
    🔗
    🔗

    Example 1.4.4.

    The equation \(y'=y^2+y+3\) is separable with \(g(x)=1\) and \(h(y)=y^2+y+3\text{.}\) This equation is also autonomous. In fact, all autonomous equations are also separable.
    🔗
    🔗

    Example 1.4.5.

    The equation \(y'=x+1\) is separable. (It falls into our first special case above. Any equation where the right-hand side only has one variable is separable.)
    🔗
    We can in fact solve this particular equation:
    🔗
    \begin{equation*} y = \int (x+1)\,dx = \frac{x^2}{2} + x + C \end{equation*}
    Whether we can solve this type of differential equation (or an autonomous equation) depends on the integrability of the right-hand side. For instance, the differential equation \(y'=e^{x^2}\) is separable. However, \(e^{x^2}\) has no antiderivative. If we had an initial-value problem that involved this equation, we would have to approximate the integral of \(e^{x^2}\) using numerical methods.
    🔗
    🔗
    When we have a separable equation, we can mostly solve it using the “separate and integrate” method. We first separate the variables -- all the terms with \(y\)’s in them go to the left side, and all the terms with \(x\)’s in them go the the right side. We then integrate both sides (assuming we can do so) which leads to an implicit solution of the equation. That is, we obtain an equation which gives the relationship between \(x\) and \(y\text{.}\) In many cases, we can solve this equation for \(y\text{.}\) If we can, we have an explicit solution, an actual formula for the dependent variable \(y\) in terms of the independent variable \(x\text{.}\) Obtaining an explicit solution is always the goal, though it’s not always possible.
    🔗

    Example 1.4.6.

    Suppose that we wish to solve the differential equation \(y'=-xy^2\text{.}\) This equation is separable with \(g(x) = x\) and \(h(y)=-y^2\text{.}\) (It doesn’t matter where we put the minus sign since we can move it as needed.) We first rewrite the left-hand side in Leibniz notation:
    🔗
    \begin{equation*} \frac{dy}{dx} = -xy^2. \end{equation*}
    🔗
    We then separate the variables, moving the \(y\) pieces to the left and the \(x\) pieces to the right, remembering that the differentials \(dx\) and \(dy\) must be in the numerators of any fractions that result. Thus we divide both sides by \(-y^2\) and multiply both sides by \(dx\text{.}\)
    🔗
    \begin{equation*} - \frac{dy}{y^2} = x\,dx \end{equation*}
    We rewrite this in the forms:
    \begin{align*} -\frac1{y^2}\,dy \amp = x\,dx\\ -y^{-2}\,dy\amp = x\,dx \end{align*}
    We can now integrate both sides with respect to the separate variables to get
    \begin{align*} -\frac{y^{-1}}{-1} \amp = \frac{x^2}{2} + C\\ \frac1{y} \amp = \frac{x^2}{2} + C \end{align*}
    This last equation is an implicit solution to our differential equation. Notice that we put a single constant of integration on the right-hand side. In this case, we can get an explicit solution by taking the reciprocal of both sides.
    \begin{equation*} \boxed{y = \frac1{\frac{x^2}{2}+C}} \end{equation*}
    🔗

    Aside
    Note in the last step that we must take the reciprocal of the entire right- hand side at once. The answer is not \(y=\frac2{x^2} + \frac1{C}\text{.}\) Not at all.

    🔗

    Example 1.4.7.

    Suppose we wish to solve the differential equation \(y'=x(y+1)\text{.}\) This equation is separable with \(g(x)=x\) and \(h(y) = y+1\text{.}\) Following the method of the previous example, we will separate the variables and then integrate both sides.
    🔗
    \begin{align*} \frac{dy}{dx} \amp =x(y+1)\\ \frac{dy}{y+1} \amp = x\,dx \\ \int \frac1{y+1}\,dy \amp = \int x\,dx \end{align*}
    This leads to the implicit solution
    \begin{equation*} \ln |y+1| = \frac{x^2}{2} + C. \end{equation*}
    We can actually solve this to get an explicit formula for \(y\text{.}\) We first take \(e\) to both sides to get
    \begin{align*} e^{\ln |y+1|} \amp = e^{x^2/2+C}\\ |y+1| \amp = e^{x^2/2}\cdot e^C\\ y+1 \amp = \pm e^C\cdot e^{x^2/2}. \end{align*}
    Since \(e\) is constant and \(C\) is constant, \(e^C\) is constant. To make things a little easier to read, let’s set \(A = \pm e^C\text{.}\) Then we have
    \begin{align*} y+1 \amp = Ae^{x^2/2}\\ y \amp = Ae^{x^2/2} - 1, \end{align*}
    where \(A\) can be any real number except 0. (Why?) However, we note that if \(A\) were 0, our solution would become \(y=-1\) which is also a solution of the original differential equation. So we go ahead and allow \(A=0\text{,}\) and this means that our complete solution is
    \begin{equation*} \boxed{y=Ae^{x^2/2}-1 \text{ where $A$ is any real number.}} \end{equation*}
    🔗
    The MATLAB commands to solve the equation are below.
    🔗
    🔗
    What happened toward the end of the last example with the allowable values of \(A\text{?}\) When we separated the variables, we divided by \(y+1\text{.}\) Since we’re not allowed to divide by 0, this implies that \(y\) is not allowed to be \(-1\text{.}\) In other words, we dropped \(-1\) as a possible solution. However, we are duty bound before declaring victory over a problem to check “thrown away” solutions in the original differential equation to make sure we have a complete answer. This is something you should always do as you finish up solving a differential equation.

    Subsection 1.4.3 Initial-Value Problems

    We can solve separable initial-value problems -- separable differential equations paired with an initial condition -- using the same method. In the end, the initial condition allows us to fill in the value of the arbitrary constant.
    🔗

    Example 1.4.8.

    Suppose we wish to solve the initial-value problem
    \begin{equation*} y'=\frac{x}{y}, \quad y(0)=1 \end{equation*}
    We first separate the variables and write
    \begin{align*} \frac{dy}{dx} \amp = \frac{x}{y} \\ y\,dy \amp = x\,dx \end{align*}
    We then integrate both sides to get
    \begin{align*} \int y\,dy \amp = \int x\,dx \\ \frac{y^2}{2} \amp = \frac{x^2}{2} + C \\ y^2 \amp = x^2 + 2C\\ y \amp = \pm\sqrt{x^2+2C} \end{align*}
    Using the initial condition \(y(0)=1\) (which we read as “when \(x=0\text{,}\) \(y=1\)”), we can determine the value of \(C\text{.}\) Since \(y\) is positive, we choose the positive square root above.
    \begin{align*} 1 \amp =\sqrt{0^2+2C}\\ 1 \amp =\sqrt{2C} \Longrightarrow 1=2C \Longrightarrow C = \tfrac12 \end{align*}
    Thus the particular solution is
    \begin{equation*} y = \sqrt{x^2 + 2(\tfrac12)} \Longrightarrow \boxed{y=\sqrt{x^2+1}} \end{equation*}
    🔗
    The MATLAB commands for solving this differential equation are below.
    🔗
    🔗
    If we ask MATLAB to solve a differential equation it cannot solve analytically, it will return an error message. For instance, MATLAB cannot solve the initial-value problem
    \begin{equation*} \frac{dy}{dx} = \sin(xy), \qquad y(0)=1 \end{equation*}
    🔗

    Example 1.4.9.

    Consider the initial-value problem
    \begin{equation*} \frac{dy}{dx} = \frac{x}{y-x^2 y}, \qquad y(0)=4. \end{equation*}
    This equation is separable and so we first separate the variables.
    \begin{align*} \frac{dy}{dx} \amp = \frac{x}{y(1-x^2)} \\ y\,dy \amp = \frac{x}{1-x^2}\,dx \end{align*}
    We can now integrate both sides of this equation and obtain
    \begin{align*} \frac{y^2}2 \amp = -\frac12 \ln|1-x^2| + C \\ y^2 \amp = -\ln|1-x^2| + C_1, \end{align*}
    where \(C_1\) equals \(2C\text{.}\) The initial condition tells us that when \(x=0\text{,}\) \(y=4\text{.}\) This gives us
    \begin{align*} 4^2 \amp = -\ln|1-0^2| + C_1 \\ 16 \amp =0+C_1 \Longrightarrow C_1 = 16 \end{align*}
    Therefore,
    \begin{equation*} y^2 = 16-\ln|1-x^2| \Longrightarrow \boxed{y=\sqrt{16-\ln|1-x^2|}} \end{equation*}
    Notice that this solution does not make sense for all values of \(x\text{.}\) In fact, the solution is defined only for \(-1\lt x\lt 1\text{,}\) if we require our solution to be continuous. Let’s see what MATLAB has to say on the matter.
    🔗
    MATLAB does return a solution even if it looks a bit different than the one that we arrived at above. Notice that we have an imaginary term in our solution, where \(i^2=-1\text{.}\) We will examine the role of complex numbers and how useful they are in the study of ordinary differential equations in a later chapter, but for the moment complex numbers will just muddy the situation.
    🔗
    🔗

    Example 1.4.10. Logistic Growth.

    The logistic growth model we saw in Subsection 1.2.4 qualifies as a separable equation (as well as a homogeneous one). Here’s an initial-value problem we can solve using our “separate and integrate” method:
    \begin{equation*} \frac{dP}{dt} = rP\left(1-\frac{P}{1000}\right), \qquad P(0) = 100. \end{equation*}
    Our starting population is 100 and the carrying capacity for the environment we are modeling is 1000. We first separate the variables. Since \(P\) is the dependent variable, we get all the \(P\)’s on the left-hand side, and all the \(t\)’s (the independent variables) on the right-hand side.
    \begin{equation*} \frac{dP}{P(1-P/1000)} = r\,dt \Longrightarrow \int \frac1{P(1-P/1000)}\,dP = \int r\,dt. \end{equation*}
    To compute the integral on the left, we can use partial fractions to write
    \begin{align*} \frac1{P(1-P/1000)} \amp = \frac{A}{P}+\frac{B}{1-P/1000}\\ \amp = \frac{A(1-P/1000)+BP}{P(1-P/1000)} \end{align*}
    Equating the numerators of the first and last fractions there (which have the same denominators), we arrive at
    \begin{equation*} 1 = A\left(1-\frac{P}{1000}\right)+BP \end{equation*}
    Grouping by powers of \(P\) on each side of the equation, we get the system of equations
    \begin{equation*} \left.\begin{gathered} 1 = A \\ 0 = -\frac{A}{1000} + B \end{gathered}\right\} \Longrightarrow \left\{\begin{gathered} A = 1 \\ B = \frac1{1000} \end{gathered}\right. \end{equation*}
    Thus
    \begin{equation*} \frac{1}{P(1-P/1000)} = \frac1{P} + \frac{1/1000}{1-P/1000} = \frac1{P} + \frac1{1000-P}. \end{equation*}
    Coming back to our integrals, we now have
    \begin{gather*} \int\left(\frac1{P}+\frac1{1000-P}\right)\,dP = \int r\,dt\\ \ln |P| - \ln |1000-P| = rt + K \end{gather*}
    To solve for \(P\text{,}\) we exponentiate both sides and use properties of exponentials and logarithms to write
    \begin{gather*} e^{\ln |P| - \ln |1000-P|} = e^{rt+K}\\ \frac{e^{ln|P|}}{e^{\ln|1000-P|}} = e^{rt}e^K\\ \frac{|P|}{|1000-P|} = K_1e^{rt}, \end{gather*}
    where \(K_1=e^K\text{.}\) Since \(0\lt P\lt 1000\text{,}\) we can remove the absolute values on the left-hand side.
    \begin{gather*} \frac{P}{1000-P} = K_1 e^{rt}\\ P = 1000 K_1 e^{rt} - PK_1 e^{rt}\\ P + PK_1 e^{rt} = 1000K_1 e^{rt}\\ P(1+K_1e^{rt}) = 1000K_1 e^{rt}\\ P = \frac{1000K_1e^{rt}}{1+K_1e^{rt}}\\ P = \frac{1000}{Ce^{-rt} + 1}, \end{gather*}
    where \(C = 1/K_1\text{.}\) If we substitute in our initial condition \(P(0) = 100\text{,}\) we find that
    \begin{align*} 100 \amp =\frac{1000}{Ce^0 + 1}\\ 100 \amp = \frac{1000}{C+1}\\ C+1 \amp = \frac{1000}{100} = 10\\ C \amp =9. \end{align*}

    Subsection 1.4.4 Newton’s Law of Cooling

    Separable equations arise in a wide range of application problems. One does not have to watch too many crime dramas to realize that the time of death of a murder victim is an important question in many criminal investigations. How does a forensic scientist or a medical examiner determine the time of death? Human beings have a temperature of \(98.6^\circ\)F. If the surrounding temperature is cooler, then the body will cool down after death. Eventually, the temperature of the body will match the temperature of the environment. We should not expect the body to cool at a constant rate either. Think of how a hot cup of coffee or tea cools. The liquid will cool quite quickly during the first few minutes but will remain relatively warm for quite a long period.
    🔗
    The answer to our forensic question can be found by using Newton’s law of cooling, which tells us that the rate of change of the temperature of an object is proportional to the difference between the temperature of the object and the temperature of the surrounding medium. Newton’s law of cooling can be easily stated as a differential equation,
    \begin{equation*} \frac{dT}{dt} = k(T-T_m), \end{equation*}
    where \(T\) is the temperature of the object, \(T_m\) is the temperature of the surrounding medium, and \(k\) is the proportionality constant.
    🔗
    Suppose that the temperature of the surrounding environment is \(70^\circ\)F, and we know from experience that a body under these conditions cools off approximately \(2^\circ\)F during the first hour after death. In order to determine a formula for the time of death, we must solve the initial-value problem
    \begin{equation*} \frac{dT}{dt} = k(T-70), \quad T(0)=98.6, \end{equation*}
    where \(T(1) = 96.6\text{.}\) If we rewrite the equation
    \begin{equation*} \frac{dT}{dt} = k(T-70) \end{equation*}
    as
    \begin{equation*} \frac1{T-70}\,dT = k\,dt, \end{equation*}
    we see that the equation is separable. Integrating both sides, we obtain \(\ln |T-70| = kt + C\text{.}\) Since we are assuming that \(T\gt 70\text{,}\) we can remove the absolute values and write
    \begin{equation*} \ln(T-70) = kt + C \Longrightarrow T-70 = e^{kt+C} = e^{kt}e^C. \end{equation*}
    Letting \(A=e^C\text{,}\) the solution becomes
    \begin{equation*} T(t) = Ae^{kt} + 70. \end{equation*}
    The initial condition \(T(0)=98.6\) leads to \(A=28.6\text{.}\) Thus,
    \begin{equation*} T(t) = 28.6e^{kt} + 70. \end{equation*}
    Since
    \begin{equation*} 96.6 = T(1) = 28.6e^{k\cdot 1} + 70, \end{equation*}
    we can solve for \(k\text{.}\)
    \begin{equation*} k = \ln\left(\frac{26.6}{28.6}\right) \approx -0.0725 \end{equation*}
    and
    \begin{equation*} T(t) = 28.6e^{-0.0725t}+70. \end{equation*}
    The graph of the temperature \(T\) seems appropriate to our model Figure 1.4.12.
    🔗
    Let’s solve our differential equation using MATLAB.
    🔗

    Subsection 1.4.5 Mixing Problems

    There is a large class of problems in modeling known as mixing problems. These problems refer to situations where two or more substances are mixed together in a container or containers. For example, we might wish to model how chemicals are mixed together in a refinery, how pollutants are mixed together in a pond or a lake, how ingredients are mixed together when brewing beer, or even how various greenhouse gases mix together across different layers of the atmosphere.
    🔗

    Example 1.4.14.

    Suppose that we have a large tank containing 1000 gallons of pure water and that water containing 0.5 pounds of salt per gallon flows into the tank at a rate of 10 gallons per minute. If the tank is also draining at a rate of 10 gallons per minute, the water level in the tank will remain constant. We will assume that the water in the tank is constantly stirred so that the mixture of salt and water is uniform in the tank.
    🔗
    We can model the amount of salt in the tank using differential equations. If \(x(t)\) is the amount of salt in the tank at time \(t\text{,}\) then the rate at which the salt is changing in the tank is the difference between the rate at which salt is flowing into the tank and the rate at which it is leaving the tank, or
    \begin{equation} \frac{dx}{dt} = \text{rate in} - \text{rate out}.\tag{1.4.1} \end{equation}
    Of course, the salt flows into the tank at the rate of \(10 \cdot 0.5 = 5\) pounds of salt per minute. However, the rate at which the salt leaves the tank depends on \(x(t)\text{,}\) the amount salt in the tank at time \(t\text{.}\) At time \(t\text{,}\) there is \(x(t)/1000\) pounds of salt in one gallon. Therefore, salt flows out of the tank at a rate of \(10x(t)/1000 = x(t)/100\) pounds per minute. Equation (1.4.1) now becomes
    \begin{align*} \frac{dx}{dt} \amp = 5 - \frac{x}{100}\\ x(0) \amp = 0. \end{align*}
    This equation is separable,
    \begin{equation*} \frac{dx}{500 - x} = \frac{dt}{100}. \end{equation*}
    Integrating both sides of the equation, we have
    \begin{equation*} -\ln|500 - x| = \frac{t}{100} + k \end{equation*}
    or
    \begin{equation*} \ln|500 - x| = - \frac{t}{100} - k. \end{equation*}
    Consequently,
    \begin{equation*} 500 - x = C e^{-0.01t}, \end{equation*}
    where \(C = e^{-k}\text{.}\) From our initial condition, we can quickly determine that \(C = 500\) and
    \begin{equation*} x(t) = 500 - 500 e^{-0.01t} \end{equation*}
    models the amount of salt in the tank at time \(t\text{.}\) Notice that \(x(t)\to 500\) as \(t \to \infty\text{,}\) as expected.

    Subsection 1.4.6 A Retirement Model

    Differential equations have many applications in economics and finance. For example, Dr. P., a college professor, wisely started saving for his retirement as soon as he entered the workforce, and he now has $500,000 in a retirement account earning an interest of 5% compounded continuously. The initial value problem,
    \begin{equation*} \frac{dP}{dt}= 0.05 P, \qquad P(0) = 500 \end{equation*}
    provides a nice model of Dr. P.’s investment, where \(P(t)\) is the amount in thousands of dollars in the fund at time \(t\text{.}\) The solution to our initial value problem is
    \begin{equation*} P(t) = 500e^{0.05t}. \end{equation*}
    If Dr. P. plans to retire in 10 years, he can expect a nest egg of \(P(10) \approx 824.360635350064\) or about $824,360.
    🔗
    Of course, Dr. P. still plans to make contributions to his retirement fund during his next ten years of employment. His annual contribution will be $5,000, which his employer will generously match. If we assume that these contributions will spread out evenly over the course of the year, we can incorporate this information into our original initial value problem,
    \begin{equation*} \frac{dP}{dt} = 0.05 P + 10, \qquad P(0) = 500 \end{equation*}
    This differential equation is separable, so we have
    \begin{equation*} \int \frac{dP}{0.05P + 10} = \int dt. \end{equation*}
    Integrating both sides of this equation, we have
    \begin{equation*} 20\ln|0.05P + 10| = t + k, \end{equation*}
    where \(k\) is an arbitrary constant. Since \(0.05P + 10 \gt 0\text{,}\) we have
    \begin{equation*} 20\ln(0.05P + 10) = t + k. \end{equation*}
    This last equation is equivalent to
    \begin{equation*} 0.05P + 10 = e^{0.05(t + k)} = e^{0.05t} e^{0.05k}. \end{equation*}
    If we let \(C = e^{0.05k}\) and solve for \(P\text{,}\) we obtain
    \begin{equation*} P = 20 C e^{0.05t} - 200. \end{equation*}
    Using our initial condition,
    \begin{equation*} 500 = P(0) = 20 C e^{0.05 \cdot 0} - 200 = 20 C - 200, \end{equation*}
    we have \(C = 35\text{.}\) Thus, the solution that we seek is
    \begin{equation*} P(t) = 700e^{0.05t} - 200. \end{equation*}
    Dr. P.’s nest egg is now \(P(10) \approx 954.104889490090\) or about $954,105.
    🔗
    Once Dr. P. retires, he will need to begin withdrawing money from his account. He estimates that he will need to withdraw $60,000 a year for living expenses if he wishes to travel and enjoy his golden years. Of course, whatever remains in his account at any given time will still collect interest. We describe Dr. P.’s retirement situation with the initial value problem,
    \begin{align*} \frac{dP}{dt} \amp = \begin{cases} 0.05 P + 10, \amp t \leq 10 \\ 0.05 P - 60, \amp t \gt 10 \end{cases}\\ P(0) \amp = 500. \end{align*}
    If \(P = 954\text{,}\) then
    \begin{equation*} \frac{dP}{dt} = 0.05 P - 60 \approx -12.3 \lt 0. \end{equation*}
    Hence, the rate of withdrawal exceeds the rate at which Dr. P.’s account is earning interest. Eventually, Dr. P.’s retirement fund will disappear. This may pose a problem, if Dr. P. plans to retire early and live a long life.
    🔗
    Again, the differential equation \(dP/dt = 0.05 P - 60\) is separable, and we have
    \begin{equation*} \int \frac{dP}{0.05P - 60} = \int dt. \end{equation*}
    Integrating both sides of this equation yields
    \begin{equation*} 20\ln|0.05P - 60| = t + k. \end{equation*}
    Since \(0.05 P - 60 \lt 0\text{,}\)
    \begin{equation*} |0.05P - 60| = 60 - 0.05P, \end{equation*}
    and
    \begin{equation*} 20\ln(60 - 0.05P) = t + k. \end{equation*}
    Consequently,
    \begin{equation*} 60 - 0.05P = e^{(t + k)/20}, \end{equation*}
    or
    \begin{equation*} P = 1200 - C e^{0.05t}, \end{equation*}
    where \(C = 20e^{k/20}\text{.}\) Now, we can apply our initial condition \(P(10) = 954\) to determine that \(C \approx 149.21\text{.}\) Therefore,
    \begin{equation*} P = 1200 - 149.21 e^{0.05t} \end{equation*}
    describes how much money Dr. P. has after he retires (\(t \geq 10\)).
    🔗
    If Dr. P. wants to know how long his retirement fund will last, he must solve the equation
    \begin{equation*} 1200 - 149.21 e^{0.05t} = 0. \end{equation*}
    In this case,
    \begin{equation*} t = 20 \ln\left( \frac{1200}{149.21} \right) \approx 41.7. \end{equation*}
    This means that if Dr. P. retires in 10 years at the early age of 55, he can expect his retirement to last into his mid-90s.

    Subsection 1.4.7 What Can Go Wrong

    Not all separable first-order equations can be solved analytically. Even if we can, it may be impossible to find an explicit solution.
    🔗

    Example 1.4.17. No Explicit Solution.

    Consider the equation
    \begin{equation*} \frac{dy}{dx} = \frac{y(1 + y^2)}{y^2 + y + 1}. \end{equation*}
    This equation can be rewritten in the form
    \begin{equation*} \left( \frac{1}{1+ y^2} + \frac{1}{y} \right) \, dy = dx \end{equation*}
    (Use partial fractions.) Integrating both sides of the equation, we have
    \begin{equation*} \arctan y + \ln|y| = x + C. \end{equation*}
    However, we have no method of solving this last equation explicitly for \(y\text{.}\)
    🔗
    🔗

    Example 1.4.18. Un-integrable functions.

    Consider the equation
    \begin{equation*} y'=xe^{-y^2}. \end{equation*}
    This equation is separable since we can rewrite it in the form
    \begin{equation*} e^{y^2}\,dy = x\,dx. \end{equation*}
    Although the Fundamental Theorem of Calculus guarantees that every continuous function has an antiderivative, we cannot find an antiderivative for the function \(e^{y^2}\) in terms of elementary functions. Thus, we are forced to write our solution as
    \begin{equation*} \int_0^y e^{s^2} \, ds = \frac{1}{2} x^2 + C. \end{equation*}
    🔗
    🔗

    Example 1.4.19. Non-linear equations.

    Even if we have a separable differential equation, we are not guaranteed a unique solution. Consider the initial value problem \(y' = y^{1/3}\) with \(y(0) = 0\) and \(x \geq 0\text{.}\) Separating the variables,
    \begin{equation*} y^{-1/3} \, dy = dx. \end{equation*}
    Thus,
    \begin{equation*} \frac{3}{2} y^{2/3} = x + C \end{equation*}
    or
    \begin{equation*} y = \left( \frac{2}{3} ( x + C)\right)^{3/2}. \end{equation*}
    If \(C = 0\text{,}\) the initial condition is satisfied and
    \begin{equation*} y = \left( \frac{2}{3} x \right)^{3/2} \end{equation*}
    is a solution for \(x \geq 0\text{.}\) However, we can find at least two additional solutions for \(x \geq 0\text{:}\)
    \begin{align*} y & = - \left( \frac{2}{3} x \right)^{3/2},\\ y & \equiv 0. \end{align*}
    This does not violate Theorem 1.1.23 because this differential equation is non-linear.
    🔗
    🔗

    Example 1.4.20. Different Intervals, Different Solutions.

    Suppose that \(y' = y^2\) with \(y(0) = 1\text{.}\) Separating the variables,
    \begin{equation*} \frac{1}{y^2} \, dy = dx, \end{equation*}
    we see that
    \begin{equation*} y = - \frac{1}{x + C}. \end{equation*}
    Using the initial condition to solve for \(C\text{,}\) we get
    \begin{equation*} y = \frac{1}{1-x}. \end{equation*}
    This function has a vertical asymptote at \(x=1\text{.}\) Because we have an initial condition at 0, by Theorem 1.1.23, this solution is valid on all of \((-\infty, 1)\text{.}\)
    🔗
    On the other hand, suppose instead that \(y(0) = -1\text{.}\) Then the solution is
    \begin{equation*} y = - \frac{1}{x + 1}, \end{equation*}
    and this solution is valid on \((-1, \infty)\text{.}\)

    Subsection 1.4.9 MATLAB -- Quick Start Guide to Solving Ordinary Differential Equations

    MATLAB (and Octave) has powerful algorithms for finding exact and numerical solutions of differential equations. In addition, we can plot solutions and direction fields. Although some differential equations have an exact solution and can be solved using analytic techniques with calculus, many differential equations can only be solved using numerical techniques. This should not be too surprising if we consider how we solve polynomials. It is quite easy to find the roots of any equation of the form \(ax^2 + bx + c = 0\) by either factoring or using the quadratic equation, but solving an equation such as
    \begin{equation*} 5x^7 - 6x^4 +3x^3 -23 x^2 +3x -17 = 0 \end{equation*}
    is a much more difficult problem. Unlike the situation for quadratic equations, there does not exist a general formula for solving seventh degree equations. We can even encounter difficulties when using a numerical method such as the Newton-Raphson algorithm.
